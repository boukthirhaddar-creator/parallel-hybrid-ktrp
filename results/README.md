# Generated output

`tables_from_logs.txt` is the complete output of

```bash
python reproduce_tables.py
```

as produced on the machine described in the root `README.md`. It is committed so
that a reader can compare their own run against ours without executing anything,
and so that any divergence is immediately visible.

Running `python reproduce_tables.py --check` compares twenty-seven headline values from
the paper against the values recomputed from the logs and exits with status 0 when
all agree.
